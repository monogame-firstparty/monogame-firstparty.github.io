# Mono Hangman

A 1-bit retro hangman puzzle built on the Mono fantasy console, using the fifty
words Dr Seuss famously used to write a book on a bet. Clear all fifty and
unlock an ending scene that celebrates how strict constraints can fuel
creativity.
